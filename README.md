# CareFlow Serverless

A small serverless healthcare workflow app built to learn and practice AWS services.

## AWS Services

- Cognito — authentication
- AppSync — GraphQL API
- Lambda — backend logic
- DynamoDB — data storage
- SQS — background jobs
- S3 — file storage
- CloudWatch — logging and monitoring
- CDK / CloudFormation — infrastructure as code

## Goal

Build a simple request workflow while learning how AWS serverless services work together in a real application.
